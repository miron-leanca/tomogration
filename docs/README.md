# docs/

Images and supplementary docs for Tomogration.

**`screenshot.png`** — the main-window screenshot referenced by the top-level
`README.md`. Save your screenshot here with exactly that name:

```
docs/screenshot.png
```

(PNG, the full app window is ideal.) Once it's there, the image will render on the
repository landing page. Until you add it, the `![…](docs/screenshot.png)` line in
the README will show as a broken-image placeholder — harmless, just add the file.
