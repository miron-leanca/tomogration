# docs/

Images and supplementary docs for Tomogration.

**`screenshot.png`** — the main-window screenshot referenced by the top-level
`README.md`. To refresh it, save a new full-window PNG over this file (same
name), and the repository landing page picks it up.

**`tomogration_pipeline_reference.html` / `.pdf`** — the printable pipeline
reference, generated by `make_pipeline_reference.py`.
